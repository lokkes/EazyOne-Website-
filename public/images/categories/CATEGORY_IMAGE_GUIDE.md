# Category Image Upload Guide

Add one WebP image for each homepage category using these exact filenames:

- `flannel-shirts.webp`
- `hooded-flannels.webp`
- `overshirts.webp`
- `shorts.webp`
- `sleepwear-loungewear.webp`

All five files belong in this folder. Images should preferably use a portrait
4:5 aspect ratio so they fit the existing cards without awkward cropping.
