## Catalogue Product Images

Every SKU has its own folder under `public/images/products/`. Each gallery
uses these exact filenames:

```text
public/images/products/EZO-FS-001/01.webp
public/images/products/EZO-FS-001/02.webp
public/images/products/EZO-FS-001/03.webp
public/images/products/EZO-FS-001/04.webp
```

Use the same `01.webp` through `04.webp` convention for every other SKU.
See `docs/PRODUCT_IMAGE_UPLOAD_GUIDE.md` for the full 60-SKU list.
